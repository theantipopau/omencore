## OmenCore 5.0.0 is out

The biggest release so far. Update from inside the app (the update button in the header, or F5); your settings carry over.

**What's new**
- **Modes remember the whole machine.** Performance, Balanced, Quiet and your own modes can now carry a fan preset or curve, GPU Power Boost, refresh rate, lighting and charge limit, not just wattages. Your 4.x modes load unchanged.
- **Every greyed-out control tells you why.** Model database, firmware, a safety rule or runtime detection: the reason is shown on the page and included in the diagnostics export.
- **Faster start, less memory.** CPU detection no longer waits on WMI (about 2 s saved on a cold boot), and idle memory is lower. CI now checks both, so they don't creep back.
- **Refreshed interface.** The window follows your active mode's colour, you can zoom it, it follows Windows high-contrast themes, and the shell is available in Russian and Turkish.
- **Safer updates.** Downloads are checked against the release's own `SHA256SUMS` file, and every release has GitHub build provenance.
- **Safer uninstall and upgrade.** The installer hands the fans back to the BIOS, so fans left at Max no longer stay pinned after an uninstall.
- **Settings migrate.** A 4.x config is upgraded, and a copy of the original is kept next to it.

**Not in this one yet (planned for 5.1):** signed binaries (SmartScreen still says "unknown publisher"), a UI that doesn't run as administrator, and translations for the remaining pages.

Hardware-facing changes are tested in software; please report how they behave on your board.
